# PO The Grands

เว็บขอและติดตามใบ PO แยกจากระบบ Grandhouse โดยสิ้นเชิง ทั้งโค้ด บัญชี ฐานข้อมูล และการเผยแพร่

## เปิดในเครื่อง

ใช้ Node.js 22 ขึ้นไป รัน `npm ci` แล้ว `npm start` จากโฟลเดอร์นี้ เว็บอยู่ที่ http://localhost:4180/

เมื่อยังไม่ใส่ค่า Supabase เว็บทำงานในโหมดสาธิต:

1. เปิดครั้งแรก เจ้าของตั้งรหัสผ่านของตนเอง
2. เข้าด้วยชื่อบัญชี `owner` หรือชื่อบัญชีที่ตั้งไว้ เจ้าของสร้างชื่อ Login ออฟฟิศ เช่น `purchase.fai01` ระบุชื่อที่แสดงเป็นชื่อพนักงาน ตั้งรหัสผ่านตัวเลขหรือตัวอักษรอย่างน้อย 6 ตัว และเลือกสิทธิ์ดู/Export รายงานรวมให้บัญชีหลัก
3. กด “เปลี่ยนบัญชีผู้ใช้งาน” เพื่อออกจากระบบและเข้าสู่บัญชีอื่น

บัญชีออฟฟิศทั่วไปเห็นเฉพาะใบ PO ที่ตนเองเปิด บัญชีหลักเห็นใบ PO ของทุกคนและเลือกกรอง “เฉพาะของฉัน” ได้ ส่วนเจ้าของเห็นใบ PO ของทุกคนเพื่อดำเนินการอนุมัติ

ข้อมูล PO และบัญชีในโหมดสาธิตเก็บเฉพาะใน browser เครื่องนี้ ใบ PO ที่เปิดใหม่และการเปลี่ยนสถานะยังอยู่หลังรีโหลดหน้า รหัสผ่านสาธิตเก็บเป็น PBKDF2 hash เพื่อทดสอบหน้าจอเท่านั้น

## ขั้นตอนงาน

1. ออฟฟิศเลือกวันที่ PO (ค่าเริ่มต้นคือวันนี้) แล้วกรอกชื่อสินค้า สเปค แหล่งซื้อ จำนวน ราคาต่อหน่วย ภาษี และหมายเหตุ
2. ราคาที่กรอกเป็นราคาสุทธิต่อหน่วย หากติ๊ก VAT ระบบแยกฐานราคาและ VAT 7% แบบรวมภาษีด้วยสูตร VAT = ยอดรวม × 7/107
3. ออฟฟิศตรวจหน้าสรุปก่อนเปิด PO; เวลาเปิดใบใช้เวลาจากระบบ
4. เจ้าของอนุมัติ หรือไม่อนุมัติพร้อมเหตุผล
5. ออฟฟิศยืนยันว่าได้รับสินค้าครบ
6. เจ้าของยืนยันว่าได้รับใบกำกับภาษีแล้วจึงปิด PO
7. ออฟฟิศใช้หน้าสรุปรายเดือนรวมยอดใบที่อนุมัติแล้ว รับสินค้าแล้ว หรือปิดแล้ว และส่งออกเป็นไฟล์ Excel `.xlsx`; เจ้าของจัดการบัญชีและอนุมัติใบ PO โดยไม่เห็นเมนูสรุปรายเดือน

## ตรวจสอบ

รัน `npm test` และ `npm run check` การทดสอบฐานข้อมูลใช้ PGlite แยกจากข้อมูลจริง ไม่มี Supabase project จริงถูกเรียกใช้

`dist/` เป็น source เว็บพร้อม deploy ไม่ต้อง build และไฟล์ ExcelJS ถูกเก็บไว้ใน `dist/vendor/` พร้อมใบอนุญาต
